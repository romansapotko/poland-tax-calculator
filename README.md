# Калькулятор зарплаты в Польше

Веб-калькулятор для ориентировочной оценки зарплаты «на руки» в Польше по параметрам 2026 года. Это статический сайт: для работы не нужны серверная часть, сборка или установка зависимостей.

## Возможности

- Расчёт дохода по договорам **umowa o pracę**, **umowa zlecenie** и **umowa o dzieło**.
- Расчёт для **B2B/JDG** с формами налогообложения **liniowy**, **ryczałt** и **skala**; для ryczałt можно выбрать ставку.
- Учёт ZUS, медицинского взноса, PIT и стоимости сотрудника для работодателя, где применимо.
- Настройки льгот и взносов: PIT-2, ulga na powrót, ulga dla młodych, статус студента, PPK и авторские расходы.
- Итоги за выбранную часть года, разбивка дохода и помесячная таблица для трудовых договоров.
- Адаптивный интерфейс для мобильных устройств; введённые параметры сохраняются в браузере.

## Важно

Расчёты ориентировочные и не заменяют консультацию бухгалтера. Используются ставки и лимиты 2026 года, указанные в калькуляторе. Для B2B предполагаются одинаковые доходы и расходы каждый месяц выбранного периода. Не учитываются, в частности, Mały ZUS Plus и совмещение B2B с работой по найму. Фактические суммы зависят от индивидуальной ситуации и действующих правил.
